# Persona — the positive register (taste, references, gravity)

**What this is.** The generative half of the design contract. `voice-anchors.md` + the banned rules name what
Adil **refuses**; this file names what he is **aiming at** — the worldview, the named references, the
composition discipline, and the material gravity. The refusals raise the floor; this file sets the
direction. It exists because output that passes every banned rule and every detector rule can still fail the
eye — and until now nothing in the register said *why*.

**Where it binds.** Platform-agnostic — the web hub (`impeccable-hub` §2) and the iOS hub
(`ios-impeccable-hub` §2) both point here, beside `voice-anchors.md`. Lane FORWARD seeds draw from this
file at bind time (`design-lane.md` Step 1); builders read it before composing; validators judge
persona-sourced FORWARD ids as binding and everything else here as advisory-on-taste.

**Precedence (unchanged).** This file is tier-2 of the aesthetic: the owner's explicit, in-context
instruction outranks it, always. It is not a detector; it never blocks by itself and never suppresses a
detector rule. And it is **judgment + gravity, NOT a house style** — the anti-convergence law
(hub §2: "No design should be the same across projects") outranks every leaning below. If two projects
come out looking the same, this file was misread.

**Provenance.** Distilled from the 2026-07-11 interview. Quotes are owner-verbatim and load-bearing;
edits that dilute them must be refused (`#POISON_PATH`). This file is the single canonical home of the
positive register — the 2026-07-11 quotes live HERE, not in `voice-anchors.md` (which remains the home
of the voice-anchor sessions).

## 1. The mission: kill "basic" (the flatness problem)

> "The output always underwhelms in its basicness — that's the biggest issue. Even if well executed,
> it just feels flat."

> "It still registers as basic — while not AI slop, still AI weirdness."

The detector kills named slop. Nothing until now aimed the work at *composed*. Flat is a specific,
diagnosable failure: **competent execution with no compositional intent** — no entry point for the eye,
no pace, no hierarchy of attention, every choice defensible and none of them motivated.

The persona's one-line job: **every screen must be composed** — the eye lands somewhere deliberate, is
carried somewhere deliberate, and the space in between has rhythm.

### The basic-tells (the "still feels AI" fingerprints)

These are not detector rules — they are the fingerprints of flat work. None is banned outright; each is
**guilty until context-motivated**. Reaching for one requires a reason you can state.

| Tell | The failure |
|---|---|
| The mono eyebrow reflex | "The eyebrow obsession, in mono font" — an all-caps mono label as the default opener of every section. It is a training-data tic, not a decision. The mono whitelist (`preferences/typography-mono.md`) permits eyebrows; the persona asks whether THIS section needed one at all. |
| Too-large typography | A general disposition toward oversized display type — size as a substitute for hierarchy. Hierarchy comes from structure, weight, and space first; size contrast is one instrument, not the instrument. |
| Bubble/box obsession | Containers as generated defaults — "bubbles or boxes that don't seem refined at all." A card, chip, or pill must be a considered object (its radius, its border, its tint each chosen), or the content should sit on the page unboxed. |
| Uniform rhythm | Same padding, same card, same gap, top to bottom. Uniform rhythm is flat by construction — pace requires variation (§4). |
| Walls of text | Cognitive overload as a layout choice. Break with imagery, layout shifts, density changes — "use images, or layout differences." |

## 2. The first law: context over reflex

> "I hate anything that registers as 'default behavior / training data says do X when Y' — it's almost
> always wrong. (i.e. eyebrow labels, left side borders, or anything that's random rather than based on
> the context of the page/brand/screen — bubble or box design should be thoughtful, not generated
> defaults)."

> "It's always fluctuating between extreme machine precision to the brand or AI slop defaults, never
> actually responding to the directives around things like balance, pace — and often unable to apply
> the right typography, color, or layout principles for what the actual context/subject matter is and
> the user-intent behind it."

Two failure poles, one shape:

- **The slop-default pole** — the training-data reflex: do X because interfaces like this usually do X.
- **The brand-machine pole** — applying the brand spec with mechanical precision and zero judgment:
  every token correct, every rule followed, nothing interpreted.

The target is the middle, and the middle is **judgment**: the brand and the register interpreted per
surface, per subject matter, per user intent. Balance and pace are directives to be *responded to*, not
constraints to be *satisfied*.

**The operational test:** for each significant choice — this typeface at this size, this container,
this density, this motion — can you name the **context fact** (page purpose, brand register, subject
matter, user intent) that motivated it? If the only motivation is "this is what one does," stop. That
choice is a reflex wearing a decision's clothes.

## 3. What great looks like — the references

The banned rules are fences; these are targets. **Steal the WHY, never the artifact** — a reference is a
discipline to internalize, not a skin to apply (anti-convergence outranks gravity).

### Object / industrial

Rams-era **Braun**, modern **Apple hardware** (the hardware — see the anti-bar below), **Bang &
Olufsen**, **Porsche**, **Leica**, **Teenage Engineering**.

Take: exact structure, honest surface. The object carries what it is without announcing (the
Nike/Porsche mode from the anchors). Controls sit where hands expect them. Material is real, not
rendered-on. In software terms: the interface as a machined object — tolerances tight, nothing
decorative pretending to be structural.

### Fashion / editorial

**Hedi Slimane** — severity as elegance. Monochrome confidence, photographic austerity, the precision
of a silhouette as the precision of a layout. **Rick Owens**, the minimal register — "leaning minimal,
black, not the crazy stuff": weight, restraint with an edge, black-as-a-complete-palette. **Virgil
Abloh × Air Jordan 1** — the confident single gesture on a canonical object; recontextualizing the
familiar with craft and cultural certainty.

Take: the confidence. One strong idea, executed exactly, is worth ten hedged ones. *(Held with a named
caveat: Abloh's literal annotation device — the quotation marks — is precisely what "there is nothing
uglier than annotated art" refuses. Take the boldness of the gesture; never the announcing.)*

### Type foundries

**Grilli Type**, **Lineto**, **Klim** — the specimen-site mode.

Take: typography carrying the *entire* design. Type treated as a physical object with a voice; the
confidence to let a typeface be the interface. Type choices are critical — the typeface decision IS a
brand decision, made at foundry-grade attention, never delegated to a reflex list (the font-selection
procedure in the hub stands).

### Swiss / typographic modernism

**Müller-Brockmann**, **Vignelli**.

Take: hierarchy from structure, not decoration. The grid as an instrument — mastered, then broken
intentionally. Scale relationships that are *composed*, not defaulted.

### Motion-led web

The Awwwards-minimal register: sleek, polished, thoughtful motion — directional, never perspective
(the motion anchors stand).

Take: motion as a material property of the interface, not a garnish. High-impact moments over scattered
micro-interactions; the transition that explains where a thing came from.

### The digital bar (screens to hold work against)

- **Linear** — dense-but-composed SaaS; typographically quiet; zero decoration; proof that density and
  restraint coexist.
- **SSENSE-tier fashion e-commerce** — editorial type, ruthless negative space, imagery as the
  interface.
- **Foundry specimen pages** — type-led interactive confidence.
- **Perplexity (the app)** — a high-use, high-frequency product that stays composed under daily load.
- **Flighty** — the proof that data-dense consumer software can be beautiful: information-rich,
  hierarchy exact, fiercely opinionated defaults.

**The anti-bar (named, so the ceiling is honest):** Google's apps — design authority nowhere. And
**Apple's first-party apps are NOT the target** — "underwhelming to say the least." Stock-fidelity is
the floor the iOS banned rule (`ios-default-reflex`) already refuses; the bar sits above the platform default,
not at it.

## 4. Composition — where the eye goes

The hub's "balance as organizing principle," made operational. This is the discipline whose absence
produces flat.

1. **Name the entry point.** Every new page/screen has a deliberate first landing for the eye. Decide
   it before building; if you cannot say where the eye lands first, the composition does not exist yet.
2. **Carry, don't announce.** The composition moves the viewer from the entry point to the destination
   without labels doing the work — the immersive mode: "carries what the product is in a way that's
   immersive, without announcing."
3. **Negative space is an active material.** "Letting things breathe when appropriate and dense when
   appropriate" — a per-moment judgment, never a global style. Air is spent, not left over.
4. **Pace.** A page or flow has rhythm: sections vary in density, scale, and register. Uniform rhythm
   (§1, basic-tells) is flat by construction; variation is where composition lives.
5. **Balance ≠ symmetry.** Optical over geometric, weight distributed with intent — and alignment
   underneath it is non-negotiable ("I do not fuck around with alignment"; the OCD rules and
   `alignment-precision.md` stand).
6. **Scale as registration.** Don't miniaturize what matters; don't inflate what doesn't — and don't
   reach for display sizes to fake a hierarchy that structure should carry (§1, too-large tell).

## 5. Product behavior (how it behaves, not just how it looks)

Surface taste and product judgment are one discipline. The behavioral register:

- **Strong defaults, few settings.** The product decides and is right — the Apple-device-out-of-the-box
  feeling. A preferences screen is usually a deferred design decision.
- **Complexity revealed on demand.** The first screen is calm; power appears when reached for. The
  product never shows off everything it can do (showing off is announcing).
- **Right density per moment.** Dashboards and data surfaces can be DENSE (Flighty, Linear are the
  proof); moments of focus get air. Density is a per-screen judgment, not a global style.
- **No cognitive overload.** Walls of text are broken with imagery, layout shifts, and density changes.
  Every screen should be able to answer: *what is the ONE thing this moment asks of the person?* (This
  is the felt-state spine, `interfaces-that-feel`, stated behaviorally.)

## 6. The gravity (material leanings — pulls, not laws)

Where Adil's hand tends when context doesn't argue otherwise. Gravity is a starting pull, never a
prescription — **context outranks gravity; gravity outranks reflex**; anti-convergence outranks all of
it. Never let the gravity produce the same design twice.

- **Color:** material-derived over synthetic — brass/gold where the reflex says orange; deep cobalt or
  obsidian where the reflex says tech blue; sand/eggshell neutrals, never Tailwind's. Near-black /
  near-white monochrome held as a complete, confident palette (the Slimane/Owens register — the
  no-pure-`#000`/`#fff` craft rule still applies). *(Web-lane gravity: on iOS the 2026-07-02 color
  principle governs — Klein-blue primary + duty-scoped supporting color,
  `preferences/color-principle.md` / CLAUDE.md §6.1. Colorblind kernel unchanged everywhere: protan +
  deutran — meaning never rides on hue alone; blue↔yellow axis; never red-vs-green.)*
- **Type:** editorial confidence; 300/400 workhorse weights; italics sparingly in body, sometimes
  heavily for display; mono under the whitelist, as accent not atmosphere (unless the entire aesthetic
  is built around it — the anchor's own exception); the non-uniform scale (large-but-light H1 → big
  drop → H3 only a little larger than body → H4 body-sized, differentiated by form).
- **Motion:** smooth, elegant, directional — never perspective, never bounce; considered stagger;
  the Awwwards-minimal register at its most restrained.
- **Surface:** hairlines, flat tint steps, real texture over rendered effects; depth as a choice made
  each time, never a reflex.
